# 📰 News Explorer

A **full-stack web application** that lets users explore news articles, save their favorites, and manage a personal reading list. Built with a **React.js frontend** and a **Node.js / Express backend** connected to **MongoDB**, the app demonstrates **secure authentication, API integration, and user-focused design**.

---

## 🎬 Access

- GitHub: https://github.com/JoshRicks/se-fp-backend/
- Live: coming soon

## 🚀 Highlights

- **Full-Stack Development** – Designed and built both frontend (React) and backend (Node.js/Express).
- **Authentication & Authorization** – Secure JWT-based login/register system with protected routes.
- **Database Integration** – Persistent storage of saved articles using MongoDB + Mongoose.
- **REST API Design** – Built clean, documented endpoints for article management and authentication.
- **Frontend Integration** – React consumes backend APIs seamlessly, with auth state managed in the UI.

---

## 💻 Tech Stack

- **Frontend:** React.js, Context API, CSS
- **Backend:** Node.js, Express.js, MongoDB, Mongoose
- **Auth:** JWT, bcrypt
- **Other:** REST API, Postman (testing), Git/GitHub
